# Общий свет люстры

С версии 0.7.0 у каждой записи Home Control с алгоритмом **«Люстра»** автоматически
появляется сущность `light` с именем устройства. Пересоздавать записи и добавлять
helpers не нужно: обновите интеграцию и перезапустите Home Assistant.

| Яркость при четырёх группах | Включённые группы |
| --- | --- |
| 25% | 4 |
| 50% | 3, 4 |
| 75% | 2, 3, 4 |
| 100% | 1, 2, 3, 4 |

Группы используются в существующем порядке выключения. Это число включённых групп,
а не измеренная освещённость и не физическое диммирование. Ползунок HA округляется к
ближайшей доступной ступени; ненулевая яркость включает как минимум одну группу.
Для трёх групп ступени примерно 33/67/100%, двух — 50/100%, одной — 100%.

## Включение, память и кнопка

- Выключение гасит только группы люстры. Последняя ненулевая комбинация сохраняется.
- Включение без яркости восстанавливает её. До первого сохранения используются все группы.
- Если свет уже горит, включение без яркости ничего не меняет.
- Явная яркость выбирает соответствующую комбинацию, даже если свет до этого был выключен.
- С версии 0.7.1 кнопка при выключенном свете восстанавливает сохранённую комбинацию.
  Следующие нажатия в окне выбора выключают по одной включённой группе в заданном порядке;
  после истечения окна нажатие гасит весь свет. Подтверждённые изменения обновляют память.
  Например: сохранено 75% → включение кнопкой 75% → 50% → 25% → выключено.
  После такого уменьшения повторное включение вернёт последние 25%; для повышения
  яркости используйте общий свет в HA или голосовую команду.
  Выбор яркости открывает такое же окно, поэтому ближайшее нажатие продолжает цикл.
- Если перед общим выключением вручную выставлена нестандартная комбинация групп,
  она тоже сохраняется и восстанавливается. Отображаемая яркость соответствует числу групп.
- Память записывается в хранилище Home Control и переживает перезапуск. При изменении
  состава или порядка групп прежняя комбинация сбрасывается. Сам перезапуск не включает свет.
- Память обновляется по известным состояниям HA, а не по неподтверждённой цели команды.
  Это обычная обратная связь освещения, не специальный опрос, используемый для двигателя вытяжки.

Команды общего света, физической кнопки и HOLD выполняются последовательно. Служебный
переключатель **«Автоматика»** разрешает их работу. При его отключении общий свет
становится недоступным для управления; само отключение автоматики не гасит лампы.
Недоступность любой группы также блокирует команды общего света.

Ночник по HOLD не входит в общий свет и не гасится его выключением.
Специальный алгоритм **«Кухня»** не получает эту сущность: его комбинации не образуют
ступени яркости одной люстры. Вытяжка и другие процессы остаются самостоятельными.

## Голосовое управление

В используемой интеграции Яндекса выберите новую сущность `light`, например назовите
её «Свет в зале». Отдельные группы и переключатель «Автоматика» можно исключить из
голосового управления. Home Control не меняет настройки экспорта Яндекса.

Проверьте включение, установку яркости 25/50/75/100%, выключение и повторное включение.
После выключения и перезапуска HA повторное включение должно вернуть последнюю
сохранённую комбинацию. Поддержка голосовых фраз зависит от интеграции Яндекса;
проверки кода выполняются с HA Core 2026.9.3 и тестовыми сервисами реле.
